# Project Statement

## Problem Statement
Small libraries need a simple way to maintain book records and manage the issue and return of books. Manual tracking can lead to incorrect availability information and makes daily operations harder to manage.

## Scope
The project provides a command-line system for maintaining books and members and for handling book issue and return operations. It also stores book data locally so that information can be loaded during the next execution.

## Target Users
- Small library administrators
- College or school library staff
- Students learning Java application development

## High-Level Features
- View available and issued books
- Add new books
- Maintain member records
- Issue books to registered members
- Return books
- View currently issued books
- Validate user input and business rules
- Persist book information in a local file
